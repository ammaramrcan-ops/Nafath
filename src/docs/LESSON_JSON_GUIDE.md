# 📘 الدليل التفصيلي والكامل لهيكلية كود JSON للدروس (منصة نفاذ / نباهة)

يوفر هذا الدليل المرجع الشامل لكود JSON الخاص بالدروس، لسهولة إنشاء دروس جديدة أو تعديل الدروس الحالية يدوياً وبدقة عالية.

---

## 🏗️ 1. الهيكل العام للدرس (Root Lesson Schema)

كود JSON للدرس يتكون من الكائن الرئيسي الذي يحوي بيانات التعريف والإعدادات العامة ومصفوفة الفقرات التعليمية `blocks`:

```json
{
  "title": "عنوان الدرس",
  "estimatedTime": "15 دقيقة",
  "size": "3 فقرات أساسية - 10 مصطلحات",
  "topics": ["موضوع 1", "موضوع 2", "موضوع 3"],
  "enableBreaks": true,
  "breakDuration": 60,
  "blocks": [
    /* مصفوفة الفقرات التفاعلية */
  ]
}
```

### 🔹 الحقول الرئيسية:

| الحقل           | النوع           | الوصف                                              |
| :-------------- | :-------------- | :------------------------------------------------- |
| `title`         | `string`        | عنوان الدرس الرئيسي والبارز للمتعلم.               |
| `estimatedTime` | `string`        | الوقت التقديري لإكمال الدرس (مثل "20 دقيقة").      |
| `size`          | `string`        | وصف حجم الدرس (عدد الفقرات أو المصطلحات).          |
| `topics`        | `Array<string>` | قائمة العناوين أو النقاط المفتاحية المغطاة بالدرس. |
| `enableBreaks`  | `boolean`       | تفعيل أو تعطيل فواصل التنفس التلقائية بين الفقرات. |
| `breakDuration` | `number`        | مدة فاصل التنفس بالثواني (الافتراضي: 60 ثانية).    |

---

## 🎓 2. مستويات التعلم الثلاثة (Learning Levels)

تتيح المنصة اختيار واحد من المستويات التعلمية الثلاثة في شاشة الاستعداد للدرس:

1. **المستوى الأول (🌱 التعلم المباشر)**:
   - يقرأ الدرس مباشرة بدون اختبار قبلي.
   - يعرض الفكرة، الأمثلة، القصة، والنص الكامل مباشرة.
2. **المستوى الثاني (🌿 التحدي المتوسط)**:
   - يبدأ الدرس بـ **اختبار قبلي (Pre-test)** يشتمل على أسئلة **اختر من متعدد (MCQs)** لقياس الاستيعاب.
3. **المستوى الثالث (🌳 التحدي المتقدم والكامل)**:
   - يبدأ بـ **اختبار قبلي شامل** يتضمن جميع أنواع الأسئلة: **اختر (MCQs)** + **أكمل (Fill-in-the-blank)** + **أسئلة مقالية (Essays)**.

---

## 🧩 3. هيكل الفقرة التعليمية (`blocks`)

كل عنصر في مصفوفة `blocks` يمثل فقرة تعليمية تفاعلية تحوي شروحاً وأنواع أسئلة مختلفة:

```json
{
  "id": 1,
  "title": "مقدمة الغذاء",
  "short_sentence": "النباتات تصنع طعامها بنفسها باستخدام الضوء.",
  "examples": "مثل شجرة التفاح التي تبني خشبها وثمارها من الهواء والماء.",
  "story": "كان هناك شجرة تفاح صغيرة تنمو في البستان...",
  "full_text": "عملية البناء الضوئي هي العملية الحيوية التي تعتمد عليها النباتات...",
  "hard_words": [{ "word": "ذاتي التغذية", "meaning": "يصنع غذاءه بنفسه" }],
  "mnemonic": "نبات = مصنع صامت.",
  "funny_link": "النبات كائن فضائي بيشرب من رجله وبياكل شمس!",
  "mind_map_nodes": ["ذاتي التغذية", "صنع الغذاء", "طاقة الشمس", "كائن منتج"],
  "visual_url": "https://images.unsplash.com/photo-1518531933037-91b2f5f229cc",
  "quizzes": {
    "mcqs": [
      {
        "question": "النبات كائن:",
        "options": ["منتج", "مستهلك", "محلل"],
        "answer": "منتج"
      }
    ],
    "fills": [
      {
        "question": "يصنع النبات غذاءه بنفسه لذا يسمى ذاتي ____",
        "answer": "التغذية"
      }
    ],
    "essays": [
      {
        "question": "كيف تصف عملية صنع الغذاء عند النبات؟",
        "keywords": ["يصنع", "نفسه", "ضوء"],
        "hint": "تذكر دور ضوء الشمس والكلوروفيل"
      }
    ]
  },
  "zaitouna": {
    "definitions": "ذاتي التغذية: الكائن الذي يصنع غذاءه بدون الاعتماد على كائنات أخرى.",
    "reasoning": "سبب العملية: تحويل الطاقة الضوئية إلى طاقة كيميائية.",
    "links": "ترتبط هذه العملية بدورة الكربون والأكسجين في الطبيعة."
  }
}
```

### 🔹 تفاصيل حقول الفقرة:

- **`short_sentence`**: الجملة المفتاحية المختصرة المعروضة أولاً (الفكرة الأساسية).
- **`examples`**: مثال عملي ملموس يشرح الفكرة.
- **`story`**: قصة قصيرة مشوقة لتثبيت الفكرة في الذاكرة.
- **`full_text`**: النص الشامل والمكتمل للشرح.
- **`hard_words`**: قائمة الكلمات الصعبة وشرح معناها عند النقر عليها.
- **`mnemonic`**: الاختصار والرمز الذكي المساعد للحفظ.
- **`funny_link`**: الرابط الفكاهي الطريف لترسيخ الذاكرة بعيدة المدى.
- **`mind_map_nodes`**: عقود وقوائم الخريطة الذهنية التفاعلية 2D. يدعم المنشأ الصيغتين:
  - **مصفوفة نصوص بسيطة**: `["عنصر 1", "عنصر 2"]` (تولّد خريطة شعاعية تلقائية حول عنوان الدرس).
  - **كائن خريطة ذهنية كامل 2D**: `[ { "id": "map_1", "title": "عنوان الخريطة", "rootId": "root_1", "nodes": [ { "id": "root_1", "text": "...", "x": 420, "y": 220, "shape": "circle", "backgroundColor": "#213145", "lineColor": "#9d4300" } ] } ]` لإنشاء خريطة مخصصة بالمواضع والألوان والأشكال وعقد الملخص التجميعية.
- **`quizzes`**: الأسئلة بنوعيها الثلاثة (اختيار، أكمل، مقالي).
- **`zaitouna`**: ملخص الزيتونة والربط والتفكير المنطقي.
